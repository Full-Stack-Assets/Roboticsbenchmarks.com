# ADR 0005 — Rendering and design system

- Status: Accepted for Unit 0
- Date: 2026-08-20
- Owner: Design + Frontend

## Decision

Use server rendering for indexable routes, progressive enhancement for filters, URL-serialized discovery state, and CSS custom properties as the design-token source. Desktop registry tables become information-equivalent cards below 768 px.

## Consequences

Keyboard focus, reduced motion, 320 px reflow, color-independent states, and semantic HTML are acceptance requirements rather than polish.
